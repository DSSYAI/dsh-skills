# 海报提示词工艺（poster-prompt-craft）

配方来源：开源图鉴仓库 `awesome-gpt4o-images`（GitHub 上约 8.1k star，含 100 个案例）。
每个案例 = `cases\NN\case.yml`（`prompt:` 中文配方 / `prompt_en:` 英文版）+ 同目录 `example_*.png` 风格样图。
想贴近某种风格，先翻对应样图再改模板。案例作者见各 `ATTRIBUTION.yml`（转发作品请留作者名）。

## 通用公式（六件套，缺一条就"不像"）

1. **画布比例**：竖版 9:16（手账/卡片类标配），横版对比表可用 3:4→16:9
2. **背景质感**：纸质肌理米白 / 活页笔记本 / 记事本 / 纯色——必须明说一种
3. **字体层级**：标题 ≥ 正文 2 倍；只给关键词上强调色；段落之间留白
4. **内容槽位**：2~4 个小节，每节一句精炼短语；信息多就拆卡片
5. **点缀元素**：手绘图标 / 贴纸 / 和纸胶带 / 涂鸦箭头——服务内容，不许抢戏
6. **文案自给**：要展示的文字**全部自己写进提示词**，绝不许模型自由发挥（生图模型编中文必出鬼画符）

## 模板 A：知识对比卡片（评测/选型/价目类）

```text
画一张知识对比卡片，比例 9:16。
要求：
- 顶部：主标题《【主题】》+ 一句话副标题，标题字号至少是正文的 2 倍
- 主体：【N】列对比（【列1/列2/列3…】），每列一个彩色表头色块（【灰/绿/蓝/紫】），行列对齐
- 对比维度：【维度1、维度2、维度3…】，单元格文字精炼
- 下方一排总结小卡：【每列一句话点评】+ 推荐指数（实心★/空心☆）
- 字体醒目有个性；只对关键词用醒目色；段落间留白
- 背景用纸张/记事本质感图案；配少量图标增加层次，避免干扰
文案：
【把要展示的全部文字逐行写在这里】
```

## 模板 B：手绘信息图卡片（金句/感悟类，源 case 38/34 @dotey）

```text
创作一张手绘风格的信息图卡片，9:16 竖版。背景为带有纸质肌理的米色/米白色，整体质朴、亲切。
标题用红黑相间、对比鲜明的大号毛笔草书突出；正文分 2~4 个小节，每节一句精炼的中文短语；
点缀简单有趣的手绘插画或图标（人物/象征符号）；整体布局视觉平衡，预留足够空白。
文案：
【标题】
【要点1】
【要点2】
```

## 模板 C：手账拼贴流程图（教程/攻略类）

```text
创作一张手账拼贴风格的流程图海报，9:16 竖版。整体是一页螺旋活页笔记本，元素像手账贴纸拼贴：
- 顶部：手写体大标题《【主题】》+ 和纸胶带装饰 + 一条副标题横幅
- 主体：【N】个编号步骤卡片（圆角框 + 序号徽章），卡片间用蓝色手绘箭头串联成 Z 字形动线
- 每个步骤卡片：粗体小标题 + 2~3 行要点；关键注意事项用红色描边小标签强调
- 点缀：与主题相关的手绘小插画（【例：建筑/电脑/WiFi/书本…】）、星星爱心涂鸦、胶带贴纸
- 底部：一个"常见提醒"便签区（便签纸造型，2~3 条提示）
- 所有文字用清晰的中文手写风字体，层级分明，排版整齐不拥挤
文案：
步骤1：【标题：要点/要点】
步骤2：【标题：要点/要点】
…
提醒：【提示1；提示2；提示3】
```

## 工作流程（已全自动）

1. 用户给主题 → 选模板（对比选A、金句选B、教程选C）→ 填槽位出提示词
2. 生图：POST `https://tokenrhythm.studio/v1/images/generations`，body
   `{model:'qwen-image-2.0', prompt, size:'720x1280', n:1}`，Bearer 用 TOKENRHYTHM_API_KEY
   （key 在 `~\.dsh\.credentials.yaml`）。响应含 url 或 b64_json，落盘后 read_image 验收。
   wan2.7-image 同价可换，GPT-4o/豆包等用户渠道的提示词原样兼容。
   **铁律：每次生图前先向用户报单价和张数，同意后再调**（用户明文规定，2026-09-07）。
   产出图统一存到用户指定目录（未指定时用工作区下的海报产出目录）。
   质感优先的交付建议用户拿提示词去 GPT 出图：实测手账风格 GPT ≫ qwen-image-2.0
   （蜡笔质感、贴纸细节、Steam logo 一类元素都更强）；qwen-image-2.0 胜在全自动快速迭代。
3. 验收迭代（glm 看图）：重点抓**标题重字**和**卡片正文被省略**两大惯犯。
   加固咒语：标题写明"一共 N 个字，一字不多不少"；每张卡片写"必须同时包含标题和完整正文，正文不得省略"。
   首发成功率约五成，两轮内基本能过（实测 v1→v2 即过）。
4. 想扩展风格：翻仓库 100 个 `case.yml`（如 22 小红书封面、44 RPG角色卡、15 讽刺海报），照六件套公式改写
